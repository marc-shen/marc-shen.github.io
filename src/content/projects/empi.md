**ELECTROMAGNETIC WAVE-PLASMA INTERACTION (EMPI)** is a high-performance
computing (HPC) software package designed to simulate the complex interactions
between electromagnetic waves and plasma, focusing on spreading phenomena.

Authors: Nan Xu and Songyu Shen.

Article: [The EMPI Code for Plasma-induced Effects on Radio Waves. I.
Nonmagnetized Media and Applications to Fast Radio
Bursts](https://doi.org/10.3847/1538-4357/adc92d)

[View the project on GitHub](https://github.com/NanHsuX/EMPI)
