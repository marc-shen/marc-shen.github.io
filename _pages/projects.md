# Progrem on Github

## [EMPI](https://github.com/NanHsuX/EMPI){:target="_blank"}

ELECTROMAGNETIC WAVE-PLASMA INTERACTION (`EMPI`) is a high-performance computing (`HPC`) software package designed to simulate the complex interactions between electromagnetic waves and plasma, focusing on spreading phenomena.

Authors: Nan Xu, Songyu Shen.

Article: [The EMPI Code for Plasma-induced Effects on Radio Waves. I. Nonmagnetized Media and Applications to Fast Radio Bursts](https://doi.org/10.3847/1538-4357/adc92d){:target="_blank"}

## [tristan-mp-v2](https://github.com/PrincetonUniversity/tristan-mp-v2){:target="_blank"}

I am using this particle-in-cell (`PIC`) code to study plasma physics problems, including magnetic reconnection and relativistic collisionless shocks.
